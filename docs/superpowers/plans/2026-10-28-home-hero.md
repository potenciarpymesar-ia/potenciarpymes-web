# Home hero Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Implementar el hero aprobado y entregar un preview revisable.

**Architecture:** Hero aislado por clase, CSS y controlador de movimiento propios, biblioteca GSAP local. Fotografía optimizada con recorte móvil y conexiones SVG decorativas. Navegación, formularios y resto del home conservados.

**Tech Stack:** HTML, CSS, JavaScript sin framework, GSAP 3.13.0, node:test.

**Spec:** docs/superpowers/specs/2026-10-28-home-hero-design.md

## Global Constraints

- Conservar Bricolage Grotesque, Manrope y los tokens existentes.
- Texto, CTA y fotografía visibles sin JavaScript.
- Solo preview; no merge ni publicación en producción.
- No modificar CRM, Recursos o PR #6.

## Review Focus

- 320–430 px y zoom: título sin superposición, CTA legible.
- Reducción de movimiento durante reproducción: detener y restablecer escena.
- Pausa manual seguida de ocultación: no reanudar sin acción del usuario.
- GSAP o imagen no disponibles: conservar contenido y navegación funcionales.
- Salir del hero o cambiar de pestaña: detener cámara y animación decorativa.
